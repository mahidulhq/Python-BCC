✅ Step 1 — Database তৈরি করুন

XAMPP চালু করুন → phpMyAdmin খুলুন → SQL ট্যাবে গিয়ে চালান:

CREATE DATABASE fb_login;

USE fb_login;

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    userid VARCHAR(100),
    password VARCHAR(100)
);

✅ Step 2 — Folder Structure

htdocs এর ভিতরে একটি ফোল্ডার বানান:

xampp/htdocs/fblogin


ভিতরে 4টি ফাইল রাখুন:

index.html
style.css
connect.php
save.php

✅ Step 5 — Database Connection (connect.php)
<?php

$conn = mysqli_connect("localhost", "root", "", "fb_login");

if (!$conn) {
    die("Connection failed");
}

?>

✅ Step 6 — Data Save (save.php)
<?php

include "connect.php";

$userid = $_POST['userid'];
$password = $_POST['password'];

$sql = "INSERT INTO users(userid, password)
        VALUES('$userid', '$password')";

mysqli_query($conn, $sql);

echo "Login data saved successfully!";

?>
